# memo-init / prompt-generator

A **deterministic prompt compositor**: template + typed placeholders → substituted prompt + metadata
(length + sha256). No LLM call, hard validation (`PGEN-XXX`), zero runtime dependencies.

Cloned + adapted from `flowmcp-prompt-generator` (Memo 001, Kap 13 + 28; engine + 177 tests).
Generates the deterministic initial prompt of an AGENTS.md agent.
